# 改写范围

本版将上游 57 个顶层技能和 23 个工作流映射到 8 个 Codex 技能及按需加载的参考文件。它保留工程决策规则，合并入口，并调整执行方式。`migration.json` 逐项记录目标与状态；这不是逐文件或逐功能的兼容承诺。

## 保留的方法

- 先确定数据结构、使用方式和状态所有者。
- 用复现、观测和反例检验假设。
- 验证用户可观察的行为，并检查验证能否发现错误。
- 设计变化按可验证单元交付。
- 用可重复的工具降低人工检查成本。
- 将重复纠错转成架构、类型、lint 或测试约束。
- 用持久记录支持长任务和会话交接。

## Codex 适配

| 上游做法 | 本版做法 |
|---|---|
| `/poteto-mode` 等 Cursor 命令 | `$pstack` 和 7 个专项入口 |
| `Task`、`poteto-agent` 与固定模型表 | 检查当前会话工具和授权；继承模型；允许单代理执行 |
| Cursor `/loop` 和云代理假设 | 在有效会话内执行；后台持续运行需要实际可用且获授权的能力 |
| 固定浏览器控制技能 | 使用目标环境已有浏览器技能；缺失时报告验证范围 |
| 私有聊天路径和 Cursor 规则文件 | 当前任务记录、用户提供的历史、AGENTS.md 和当前权限 |
| 每次跨函数边界都设计、强制委派 | 按不确定性和影响选择设计与委派 |
| 每个流程都开 PR | 仅在当前请求包含交付时执行 |
| 自动记录团队工单或发送消息 | 保留本地结果；外部操作受任务授权约束 |
| 大量原则各占一个技能入口 | 原则合并为按需读取的参考文件 |

原版不少条目设置了 `disable-model-invocation: true`。本次按新包的快速使用目标和 Codex 默认方式重新设计发现机制：8 个入口允许自动匹配，也支持显式调用。没有复制该非 Codex 字段，也没有修改用户的全局规则。

## 未直接移植的部分

- `make-bot-ui` 的 Grok Bot webhook、发送方密钥和 Tailscale 流程。不属于通用软件工程能力。
- `automations/benny` 的服务集成、定时任务和外部工单自动化。当前包不包含后台服务。
- 上游 Bun 编排程序、PR 监控器和 TLA+ 转换脚本。本版用平台无关的任务与验证协议替代，未宣称移植这些工具实现。
- 固定多模型配置、Bugbot、Origin、Cursor 特定 API。遇到对应任务时使用实际可用的工具。
- TypeScript 专用语法目录和原版长写作目录。保留设计规则，具体语法服从项目版本和工具链。

## 安装与许可

默认安装为用户级独立副本。源码可以移动或删除，已安装技能仍可读取内部引用。每个技能都附带原版 MIT 许可，以便复制后的安装仍保留署名。

安装脚本不自动改模型、不启用额外权限、不设置插件市场、不推送仓库。插件清单和市场样例用于后续分发。本版没有发布到公开目录。
