## 独立行为试验

给一个新代理提供 `pstack-review` 技能、临时订单模块，以及用户请求“按 README 合同审查，不修改产品文件”。未提供预期答案或怀疑的缺陷；禁止联网、外部操作和继续委派。

合同要求：临时网关故障后允许相同请求 ID 重试；返回 `paid` 表示网关已成功扣款；成功后的重复请求不能重复扣款。示例代码在验证金额和调用网关之前，就把请求 ID 写入完成集合。

实际结果：代理发现完成标记写入过早。它用第一次调用抛错的网关运行探针，得到：

```text
{'retry_response': {'status': 'paid'}, 'gateway_calls': 1}
```

重试返回成功但没有第二次调用网关，违反合同。代理给出了源码位置、原因、验证命令和证据。它没有修改产品文件，没有要求不可用的工具，也没有启动额外代理。它明确说明临时目录没有 Git 历史，无法审查基线差异。

该试验验证了一条实际审查路径。它不是多模型对照，也不是整套技能的质量或性能评估。其余工作流主要经过指令、引用和权限边界检查。
